# Шрифты с моего ноутбука

Каталог шрифтов, установленных на компьютере: лицензия, поддержка языков
и права использования — всё читается прямо в браузере.

Файлы шрифтов никуда не отправляются: страница разбирает их локально
и ничего не передаёт на сервер.

- Chrome / Edge — кнопка «Показать мои шрифты» читает установленные шрифты
  (с разрешения) и дальше сама подхватывает новые.
- Любой браузер — можно перетащить папку со шрифтами в окно.
